About the Project
DermaCare is a web-based appointment management system developed for a dermatology clinic. It helps patients book appointments with doctors and allows receptionists and doctors to manage clinic activities through their respective sections.

The system is designed with three user roles: Patient, Receptionist, and Doctor. Each role has access to features according to its work.
Main Features
Patient
- Register and log in to the system.
- View the available doctors and their profiles.
- Book online appointments based on available slots.
- View appointment details and appointment history.
- View prescriptions and follow-up information.
- View and manage personal profile details.
Receptionist
- Add and update doctor details and profile photos.
- Manage doctor availability and schedules.
- View and manage patient appointments.
- Book walk-in appointments for patients.
- Cancel or reschedule appointments.
Doctor
- View their own online and walk-in appointments.
- View today's and upcoming appointments.
- Check completed appointment details.
- Write and manage patient prescriptions.
Other System Features
- Appointment scheduling with 20-minute time slots.
- Separate online and walk-in appointment bookings.
- Email notifications for appointment cancellation and rescheduling.
- Email reminders before the appointment and on the appointment day.
- Cloud storage for doctor profile photos.
Technologies Used
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Node.js, Express.js
- Database: MongoDB
- Image Storage: Cloudinary
- Email Notifications: Google Apps Script and Gmail

Project Purpose
The purpose of DermaCare is to make the appointment process easier for patients and to help clinic staff manage doctors, appointments, and prescriptions in one system.
